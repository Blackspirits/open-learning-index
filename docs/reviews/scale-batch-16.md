## Main conclusions

### Cisco defensive pathway

The strongest sequence is:

1. Introduction to Cybersecurity
2. Endpoint Security
3. Network Defense
4. Cyber Threat Management

The courses are not treated as duplicates because they progressively move from awareness into endpoint hardening, network controls/telemetry and then risk/governance/incident-response work.

Network Defense is the strongest general defensive recommendation in the category.

### Ethical Hacker

Cisco Ethical Hacker is the deepest new specialist review in this batch.

It combines:
- ten modules;
- about 70 hours;
- 34 labs;
- 86 interactive activities/quizzes;
- final exam;
- skills-based assessment.

Recommendation remains below a universal 9.5+ because the course requires prior cybersecurity knowledge and basic programming.

### Networking foundations

Cisco Networking Basics is the preferred general networking entry point.

Networking Devices and Initial Configuration is an excellent second step, but assumes the Basics-equivalent foundation.

Fortinet Networking Fundamentals is materially weaker. Its public library record is only 4–5 hours, was updated in 2023 and still exposes legacy Java-plugin compatibility guidance. It remains `advance` because it is complete and free, but Phase 4 should test whether it adds enough value beside the much stronger Cisco alternatives.

### Currency policy

Cybersecurity receives aggressive currentness scrutiny.

Live availability alone is insufficient. Reviews distinguish:
- current active Cisco career-path material;
- operating-system/platform details that age faster;
- vendor-specific product/version content;
- stale public documentation and compatibility requirements.
