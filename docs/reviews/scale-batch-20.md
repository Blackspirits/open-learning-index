## Why the scores cluster

These courses share a deliberately compact Kaggle Learn design:

- short duration;
- tutorial immediately followed by executable exercise;
- hosted notebooks or queries;
- no local setup;
- free completion certificate.

They therefore score strongly on Practice and Accessibility but materially lower on Depth than full university, Cisco or longer project-based courses.

This is not score compression by prestige. It reflects a genuinely similar microcourse architecture.

## Pandas

Kaggle's current Pandas route is approximately four hours and covers:

- creating, reading and writing data;
- indexing/selecting/assigning;
- summary functions/maps;
- grouping and sorting;
- data types and missing values;
- renaming and combining data.

The decisive advantage is immediate notebook practice. It is excellent onboarding for a learner who already knows basic Python, but it does not attempt broader statistical analysis or data-engineering depth.

## Data Visualization

The current course has eight stages and a final applied project. It covers line/bar/heatmap/scatter/distribution plots, chart selection/styling and creating independent notebooks.

Its 2026 learner route remains live and certificate-bearing. Currency is deliberately below the stable SQL routes because Seaborn/API usage is library-version-sensitive even when the underlying visualization principles remain valid.

## SQL pair

### Intro to SQL

Three hours, six tutorial/exercise pairs:

- BigQuery workflow;
- SELECT/FROM/WHERE;
- GROUP BY/HAVING/COUNT;
- ORDER BY;
- aliases and CTEs;
- joins.

The hosted environment removes infrastructure friction, which is especially valuable for beginners.

### Advanced SQL

Four hours, four focused topics:

- JOINs/UNIONs;
- analytic/window functions;
- nested/repeated data;
- efficient queries.

The course adds real value after Intro to SQL but is partly BigQuery-specific, so it should not displace a broader relational-database pathway such as freeCodeCamp's current certification.

## Intermediate Machine Learning

The current four-hour course covers:

- missing values;
- categorical variables;
- pipelines;
- cross-validation;
- XGBoost;
- data leakage.

This is a high-return practical specialist course because it targets common real-world tabular-ML mistakes and workflow quality rather than repeating introductory model theory.

Its currentness still needs more frequent maintenance than Pandas/SQL because the ML ecosystem moves faster.

## Provider concentration

Five reviews from one provider are not automatically five Phase 4 admissions.

Kaggle's practice density is genuinely strong, but Phase 4 should ask whether individual microcourses improve the published index enough to justify multiple adjacent slots, or whether a smaller set of the most distinctive Kaggle courses should represent the platform.
