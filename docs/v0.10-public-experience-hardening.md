# v0.10 public experience hardening

v0.10 turns the original static catalogue into a more complete public learning index while preserving the repository-first architecture.

The work was driven by direct visual QA, user screenshots and two independent UX/UI audits. The changes were intentionally separated from ranking, admission and evidence changes.

## Scope

v0.10 covers:

- visual redesign of the public site;
- light and dark themes;
- English and European-Portuguese public routes;
- mobile navigation and filter ergonomics;
- course-detail readability and trust presentation;
- canonical category discovery;
- a first-party SVG icon system;
- generated-site publication QA.

No course was admitted, removed or rescored as part of this cycle.

## Implemented gates

### PR #130 — modern reference design

Rebuilt the public experience around the approved visual direction:

- dedicated homepage and All Courses catalogue;
- modern hero, category discovery and featured courses;
- redesigned course-detail layout;
- responsive navigation and card system;
- original mountain artwork;
- static framework-free architecture retained.

### PR #131 — dark theme and interaction QA

Added:

- persistent light/dark theme;
- system preference as the default;
- functional Grid/List catalogue controls;
- pt-PT route fixes;
- accessible filter labels;
- cleanup of obsolete legacy rendering code.

### PR #132 — second visual QA

Fixed issues visible only after reviewing rendered screenshots:

- hero CTA/stat overlap;
- excessive card height;
- incomplete pt-PT level labels;
- language-count semantics;
- comparator display names;
- dark-mode icon surfaces.

### PR #133 — pt-PT course-detail routes

Added static European-Portuguese routes for every published course.

The interface and controlled taxonomy are localized. Provider titles and canonical editorial evidence remain in their source language to preserve auditability.

### PR #134 — accessibility and premium UX hardening

Closed the major findings shared by the external audits:

- mobile navigation restored;
- primary contrast raised;
- small informational typography enlarged;
- false favourite controls removed;
- touch targets increased;
- mobile filters collapsed and clarified;
- empty-state recovery added;
- card interaction and focus improved;
- course-detail reading hierarchy strengthened;
- status banners use verification dates;
- redundant CTAs and false tab states removed.

### PR #135 — SVG icons and canonical category discovery

Added an original project-owned SVG icon system and canonical category browsing.

New route families:

- `/categories/`
- `/categories/<id>/`
- `/pt/categories/`
- `/pt/categories/<id>/`

All 19 categories now have English and pt-PT static routes.

### PR #136 — generated-site publication QA

Added `scripts/validate_public_site.py`.

The validator checks the built artifact for:

- internal broken links and assets;
- route/canonical consistency;
- EN/pt-PT counterpart coverage;
- hreflang correctness;
- published course/category route completeness;
- sitemap coverage;
- locale declarations;
- required icon/theme runtimes;
- generated metadata consistency.

The same QA now blocks GitHub Pages deployment.

## Current architecture

The public experience remains deliberately simple:

```text
canonical JSON + editorial ledgers
            ↓
 scripts/build_public_site.py
            ↓
        static _site
            ↓
 generated-site QA
            ↓
       GitHub Pages
```

There is still:

- no CMS;
- no runtime database;
- no user account system;
- no analytics dependency;
- no frontend framework runtime;
- no hidden ranking state outside the repository.

## Remaining work

Further visual changes should be evidence-driven rather than another redesign cycle.

The next public-experience changes should only be made when one of these is true:

- live-device QA identifies a concrete regression;
- accessibility testing identifies a reproducible problem;
- user feedback reveals a recurring discovery/navigation problem;
- a maintenance change requires new public metadata or state.
