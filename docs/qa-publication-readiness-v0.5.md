## Hold exclusion and provenance integrity

The **9 current shallow `hold` records are not publication records**.

This is enforced structurally, not only editorially:

- current Deep Reviews require a current shallow decision of `advance`;
- current admission decisions require a current shallow decision of `advance` and a current Deep Review;
- `admit` decisions must exist in `data/courses.json`;
- `do_not_admit` candidates must not exist in `data/courses.json`;
- candidate records may not enter the canonical set without a current `admit` decision.

Therefore a green `scripts/validate.py` run proves that unresolved current holds cannot leak into the canonical publication set through the candidate/admission path.

The 17 retained reference fixtures are separately documented by Gate 1, preserving their pre-Phase-4 provenance rather than pretending they are Phase 4 admits.

## Generated publication surface

`data/courses.json` remains the canonical source of truth.

`data/courses.csv` is generated by `scripts/generate_csv.py`; CI then runs `git diff --exit-code -- data/courses.csv`. A green workflow therefore confirms that the spreadsheet-friendly publication surface matches the canonical JSON and is not maintained independently by hand.

The repository currently has no prior GitHub Release series. v0.5 publication readiness therefore does **not** introduce an unnecessary parallel release-maintenance structure: the repository, canonical JSON and generated CSV remain the publication surfaces defined by the project.

## Validator gate

The required workflow executes:

1. JSON Schema + repository invariant validation via `scripts/validate.py`;
2. CSV regeneration via `scripts/generate_csv.py`;
3. generated CSV parity check via `git diff --exit-code -- data/courses.csv`;
4. scheduled-review check via `scripts/check_staleness.py`.

The final publication-readiness pull request must be merged only if this complete workflow is green.

## Known limitations, not blockers

- Primary instruction remains heavily English-centric (**120 / 129**).
- Some archival courses are intentionally retained for exceptional stable teaching value and carry explicit currentness caveats.
- BLCU Elementary Spoken Chinese is cohort-dependent and its current run closes **27 December 2026**.
- British Council 2026–27 routes checked in Gate 3 batch 05 have provider-defined March 2027 closing dates.
- Fast-moving AI/software/security/vendor records remain on short 60–90 day review cadences where applicable.

None of these limitations is currently severe enough to invalidate a retained record; each has an explicit monitoring path.
