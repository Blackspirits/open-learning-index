# Phase 4 admission batch 22 — pt-PT language-access reconsideration

## Trigger

A review of the three pt-PT non-admissions from batch 21 exposed an editorial inconsistency.

The admission protocol already states that a candidate may be admitted when it provides **meaningful language or accessibility coverage without a substantial quality sacrifice**.

The earlier decisions correctly identified stronger English-language incumbents, but treated those incumbents as if they were always substitutable for Portuguese-speaking learners. That is not true when English proficiency is itself a material access barrier.

## Reconsidered candidates

All three are current, substantive and above the project's normal useful-course floor:

| Candidate | Provider level | Quality | Recommendation | Decision |
|---|---|---:|---:|---|
| `nau-fundamentos-bases-dados` | foundation / beginner-to-intermediate | 8.59 | 8.6 | **admit** |
| `nau-estruturas-dados` | intermediate | 8.43 | 8.3 | **admit** |
| `nau-ciencia-aberta-dados-fair` | intermediate | 8.44 | 8.7 | **admit** |

The previous `do_not_admit` records remain in history and are superseded.

## Why this is not a lowered quality bar

None of these courses is being promoted merely because it is in Portuguese.

- **Fundamentos de Bases de Dados** is a 25-hour relational-database course spanning conceptual/logical/physical modelling, normalization, SQL, transactions, PostgreSQL and Python integration.
- **Estruturas de Dados** is a 25-hour intermediate course covering arrays, lists, stacks, queues, heaps, hashing, trees, disjoint sets and graphs.
- **Ciência Aberta e Dados FAIR** is a current 20-hour intermediate course covering FAIR principles, data stewardship, sensitive-data security, research-data policies and responsible AI in science.

All were already Deep-Reviewed above 8.4 Quality.

The change is in the marginal-value interpretation: a stronger English course remains the global default, but it does not make a strong pt-PT route redundant for a learner who cannot effectively learn in English.

## Ranking implication

Admission does **not** mean equal ranking.

The canonical set should continue to show:
- CS50 SQL above Fundamentos de Bases de Dados on global recommendation;
- MIT 6.006 above Estruturas de Dados on intrinsic depth;
- NASA Open Science 101 above Ciência Aberta e Dados FAIR as the global open-science default.

The Portuguese courses exist as high-quality language-access alternatives.

## pt-PT computing progression

With the reconsideration, the canonical pt-PT technical pathway becomes coherent:

1. Introdução à Programação: Conceitos Fundamentais — beginner
2. Estruturas de Dados — intermediate
3. Algoritmos e Complexidade — intermediate

Fundamentos de Bases de Dados branches into a separate applied database pathway.

This is a more useful product for Portuguese-only learners than publishing only the globally strongest English resource in each role.
