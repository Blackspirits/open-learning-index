## Key decisions

### MIT Missing Semester 2026 — admit

This is not another programming course.

Its value is the layer that formal curricula often under-teach:

- shell and command-line environments;
- developer tools;
- debugging and profiling;
- Git;
- packaging;
- agentic coding;
- code quality and professional practices.

Its **10.0 Currency** matters because tooling changes much faster than algorithms or introductory programming fundamentals.

It materially complements CS50x, Odin Foundations and MIT 6.006 instead of duplicating them.

### Unity Junior Programmer — admit

Unity Junior Programmer is vendor-specific, which already lowers Recommendation relative to intrinsic Quality.

That does not erase its distinct role.

The twelve-week route adds:

- current Unity 6.x;
- C# scripting;
- debugging;
- version control;
- interfaces and scene flow;
- object-oriented programming;
- optimisation;
- publishing;
- portfolio work.

No current canonical course serves game/real-time programming directly, so this is genuine marginal coverage.

### Berkeley CS61A — do_not_admit

At **9.42 Quality**, CS61A is one of the strongest courses excluded so far.

The non-admission is deliberate.

The current canonical cluster already includes:

- CS50x;
- CS50P;
- Helsinki Python MOOC 2026;
- MIT 6.006 Algorithms.

CS61A adds valuable abstraction, interpreters and SICP-influenced pedagogy, but the public independent route lacks the full enrolled-student support/completion environment.

That extra angle is not enough to justify another foundational CS slot in a deliberately compact index.

### Web-development consolidation

The final canonical progression is intentionally compact:

1. **Odin Foundations** — beginner developer workflow and projects;
2. **Full Stack Open** — deep intermediate full-stack development.

Therefore:

- Odin Full Stack JavaScript does not add enough beside Full Stack Open;
- freeCodeCamp JavaScript does not add enough beside Odin + Full Stack Open;
- freeCodeCamp Responsive Web Design was already excluded during calibration.

This is a curation decision, not a quality rejection.

### Python consolidation

The canonical set already has two unusually strong Python choices:

- **CS50P** — polished project-led instruction;
- **Helsinki Python MOOC 2026** — very high exercise density and academic-scale scope.

freeCodeCamp Python remains a useful low-friction alternative, but a third beginner Python slot would add more duplication than value.

### Database consolidation

freeCodeCamp Relational Databases is strong and practical.

However, **CS50 SQL** is already a stronger canonical course across:

- querying;
- schema design;
- indexing;
- optimisation;
- scaling.

The extra freeCodeCamp credential and workflow do not justify another core database slot.
