## Editorial principles

### Currentness is a real gate

fast.ai remains a high-quality learning experience, but AI implementation stacks age quickly. Its older practical stack cannot be treated like a stable mathematics archive.

The canonical set already has:
- current interactive ML via Google;
- deep project-based AI via CS50 AI.

A newer specialist deep-learning route can challenge this decision later.

### Agent courses can coexist when the learning role is different

`openai-agents-workflows` remains the low-friction practical workflow incumbent.

`huggingface-agents-course` earns a second slot because it is more technical, multi-framework and implementation/evaluation-heavy. Microsoft’s Azure agent path does not add enough portable value after those two are retained.

### Microcourse quality does not imply microcourse admission

Kaggle’s hosted exercise design is excellent. But five adjacent microcourses should not become five core slots.

The platform is already represented by `kaggle-intro-machine-learning`. Pandas, visualization and SQL remain useful reviewed specialist modules without expanding provider concentration.

### Language access cannot erase a quality gap

The NAU AI/ML route adds valuable pt-PT access, but its depth/practice scores are materially below the category leaders.

This creates an explicit **pt-PT AI/ML quality-access gap**. Targeted discovery for a deeper current Portuguese route is preferable to lowering the admission bar.
